# Aman AI – تطبيق الإبلاغ عن الحوادث والحالات الطارئة

تطبيق Flutter كامل مبني حسب تصاميم Figma المرفقة، يدعم اللغة العربية بالكامل (RTL) ويستخدم خط Tajawal.

## طريقة التشغيل

1. تأكد من تثبيت Flutter SDK (الإصدار 3.x أو أحدث):
   https://docs.flutter.dev/get-started/install

2. من داخل مجلد المشروع، نزّل الحزم:
   ```bash
   flutter pub get
   ```

3. شغّل التطبيق على المحاكي أو الجهاز:
   ```bash
   flutter run
   ```

## هيكل المشروع

```
lib/
 ├─ main.dart                          # نقطة الدخول، إعداد MaterialApp و RTL

```

## أهم الميزات المطبّقة

- **شريط تنقّل سفلي عائم (Custom Floating Bottom Nav)**: حواف دائرية، ظل مرتفع، وتلوين مختلف للأيقونة النشطة:
  1. الرئيسية → `Icons.home_rounded`
  2. بلاغ → `Icons.report_problem_rounded`
  3. تتبع → `Icons.assignment_turned_in_rounded`
  4. المساعد → `Icons.smart_toy_rounded`

- **تسجيل الدخول**: مبدّل (Toggle) بين "الرقم المدني" و"رقم الهاتف" مع تغيّر نص الحقل والعنوان تلقائياً.

- **رمز التحقق (OTP)**: 4 خانات مع الانتقال التلقائي بين الحقول، وعداد تنازلي 00:59 مع إمكانية إعادة الإرسال بعد انتهائه.

- **الشاشة الرئيسية**: كارت الطوارئ الأحمر، بطاقة البلاغ النشط مع Timeline مصغّر (تم الاستلام → في الطريق → في الموقع → تم الحل)، وقائمة البلاغات السابقة.

- **إرسال بلاغ طارئ**: شبكة 2×2 لأنواع البلاغات (حرائق، حادث سير، أمطار وأودية، حالة صحية) بألوان مميزة، وحقل موقع يفتح شاشة الخريطة، وحقل تفاصيل، وزر إرفاق وسائط، وزر إرسال أحمر.

- **اختيار الموقع على الخريطة**: عند الضغط على حقل الموقع تظهر شاشة خريطة فوق الشاشة الحالية مع تضبيب (Blur) للخلفية، بها خانة بحث علوية، ودبوس ثابت في المنتصف مع خريطة قابلة للسحب، وزر "تأكيد الموقع" الذي يحفظ الموقع تلقائياً في حقل النص بالشاشة السابقة.

- **متابعة البلاغ**: رقم البلاغ، حالة "قيد المعالجة"، نسبة ثقة الذكاء الاصطناعي، Timeline تفصيلي لخط المعالجة بالتوقيتات، وزر "مشاركة الحالة".

## ملاحظات

- تم استخدام رموز Material (`Icons.*`) المذكورة في المتطلبات بدل الأيقونات الموجودة في تصاميم Figma، بحسب التعليمات.
- شاشة الخريطة مبنية برسم توضيحي (CustomPainter) يحاكي شكل الشوارع دون الحاجة لمفتاح Google Maps API؛ يمكن استبدالها لاحقاً بحزمة `google_maps_flutter` الحقيقية بسهولة داخل نفس الملف.
- جميع النصوص العربية والمسميات مطابقة تماماً لما ورد في التصاميم المرفقة.
